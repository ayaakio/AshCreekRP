# Ash Creek RP Website

A rustic, frontier-inspired website for the Ash Creek RP RedM community.

## Local preview

Open `index.html` directly in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

1. Push these files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

## Before publishing

- Replace the `#` on the **Join Our Discord** button with your Discord invite.
- Add the rules, business rules and staff pages.
- Optionally replace the abstract hero background with an approved server image.
